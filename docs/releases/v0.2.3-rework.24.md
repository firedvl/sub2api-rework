# v0.2.3-rework.24 — Accounts provider sections and reset countdowns

The Accounts Capacity view now always separates accounts into provider sections in platform order. Larger headers stay under the column headings while scrolling on desktop, and gaps separate the sections. The Group by provider toggle is removed. Each provider can still be collapsed, and the choice lasts for the browser session.

Short and long quota meters show a muted reset countdown from the window's existing reset time. Captions refresh every 30 seconds and disappear after the reset passes. Stale or estimated windows retain their warning alongside the countdown. Desktop account rows remain 52px tall. English and Chinese captions are included.

This release changes the frontend only, apart from release version metadata. No database migration, updater change, provider routing change or account configuration change is required. Schema remains 252, supported schemas 239–252, minimum updater 1.1.6, stable channel and manual update policy. The exact `.23` image and the updater's pre-install backup are the rollback target.
