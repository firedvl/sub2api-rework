# v0.2.3-rework.17 — Restore Opus 5.5 model discovery

The gateway now advertises `claude-opus-5-5` in the default Anthropic model catalog. Opus 5.5 request handling and pricing already existed, but its missing catalog entry prevented discovery and removed it from configured group model lists. The admin model selector and identity-mapping preset now include it too. Existing account mappings and group allowlists remain enforced.

Backend regression checks reproduce the missing default and configured-list entry before the fix and pass after it. The frontend model selector and preset checks pass. No schema migration, credential change or routing-policy change is required. Schema remains 252, supported schemas 239–252, minimum updater 1.1.6, stable channel and manual update policy.
