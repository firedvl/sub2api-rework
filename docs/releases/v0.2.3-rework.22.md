# v0.2.3-rework.22 — Console redesign and Ask Gateway removal

The admin and user console has new page layouts, Filters popovers, overflow menus, detail drawers, and bulk actions that appear when rows are selected. The command palette opens with Cmd/Ctrl+K or `/`, and phones have a bottom tab bar. The header shows gateway health. Overview offers an opt-in 15-second live refresh and compares totals with the same time yesterday. Entrance and row-update motion respect reduced motion.

Ask Gateway is removed from the console and backend. `POST /api/v1/admin/operator-assistant` no longer exists and returns 404.

Claude Code clients connected to the gateway with an API key do not get Claude Code’s built-in wait-for-reset behavior, which requires a claude.ai login. To wait for the reset returned by the gateway, set `CLAUDE_CODE_RETRY_WATCHDOG=1` in the client environment. See the [usage-limit contract](../CLAUDE_CODE_ACCOUNTS.md#when-every-account-is-out-of-usage).

No database migration or updater binary change is required. Schema remains 252, supported schemas 239–252, minimum updater 1.1.6, stable channel, and manual application-update policy.

Production acceptance will be recorded after publication and updater installation.
