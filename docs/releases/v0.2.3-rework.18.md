# v0.2.3-rework.18 — Claude Code model catalog and Haiku 5.5

The gateway adds Claude Haiku 5.5 and Claude Sonnet 5.5 to its default model catalog. Public discovery shows official short model IDs with readable names, merges dated aliases, and hides internal `ag-claude-*`, separate thinking variants, retired models, and unknown Claude IDs. Existing request routes still accept their configured IDs. Model allowlists, custom lists, and accounts with dated mappings recognize the equivalent official short aliases.

Haiku 5.5 supports all five effort levels, adaptive thinking, signed thinking history in Messages and Responses, forced tool calls, and a 1M context window. Pricing includes cache reads and writes and the fivefold rate increase for prompts above 100,000 tokens. Sonnet 5.5 uses the current $0.10 per million cache-read tokens. Admin suggestions include Haiku 5.5 and omit retired Claude models.

The catalog follows Anthropic's [model lifecycle](https://platform.claude.com/docs/en/about-claude/model-deprecations) and [Claude Code model configuration](https://code.claude.com/docs/en/model-config). Haiku behavior and pricing follow its [overview](https://platform.claude.com/docs/en/models/haiku-5-5/overview) and [migration guide](https://platform.claude.com/docs/en/models/haiku-5-5/migration-guide). Restricted Mythos models are excluded from the normal Claude Code catalog. Use Claude Code v2.1.293 or later for Haiku 5.5.

Regression tests cover public names and deduplication, aliases, effort levels, signed history, tool calls, and both sides of the pricing threshold. An official Claude Code request through the existing live gateway returned `OK` with Haiku 5.5 at low effort before rollout. No schema migration or account configuration change is required. Schema remains 252, supported schemas 239–252, minimum updater 1.1.6, stable channel, and manual update policy.
