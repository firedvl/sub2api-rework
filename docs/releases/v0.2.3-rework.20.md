# v0.2.3-rework.20 — Fable 5.2 and automatic model discovery

Fable 5.2 is available in the gateway catalog and admin connection-test picker. Its default prices are $8 per million input tokens, $40 per million output tokens, $10 for five-minute cache writes, $16 for one-hour cache writes, and $0.20 for cache reads. Messages and Responses preserve its signed thinking history and use adaptive thinking. The catalog advertises a 1M context window and all five effort levels.

The server refreshes supported provider inventories on startup and hourly after each completed scan. Both pickers use the saved inventory. Failed requests retain the last good snapshot. Account mappings, group allowlists, custom lists, pinned manifests, and provider visibility rules still apply. OpenAI OAuth discovery uses its canonical manifest; a legacy inventory cannot restore hidden IDs. Providers without a supported model-list endpoint retain their existing behavior. See [automatic discovery](../model-discovery.md).

The release also updates Go to 1.27.4, Brotli to 1.2.7, and klauspost/compress to 1.20.2 to clear the security findings reported by the release gate. No database migration or updater binary change is required. Schema remains 252, supported schemas 239–252, minimum updater 1.1.6, stable channel, and manual application-update policy. Model discovery runs automatically; application releases still require operator approval.
