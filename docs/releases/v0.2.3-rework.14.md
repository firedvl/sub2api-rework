# v0.2.3-rework.14 — Operator UI redesign

The operator console gains a new sidebar and header, shared theme tokens, clearer light and dark colors, page and theme transitions, and smoother menus and expandable account details. Claude account rows no longer show a dedicated Query button. Existing authentication, API, routing, account and settings behavior remains.

This release includes Go 1.27.3, DOMPurify 3.4.17 and follow-redirects 1.16.2 from the merged security update. The frontend is embedded in the application image.

The transition is `.13`/schema 252 to `.14`/schema 252. Supported schemas remain 239–252, minimum updater remains 1.1.6, and the channel and update policy remain stable/manual. Upstream remains v0.2.14 at `0363b8cdba8cec3e2ba4b2dbd49c4481143fa55d`.

Install through the host updater after image, manifest, backup and health checks. Application-only rollback to the recorded `.13` source is conditional on the updater's exact identity, state, schema and backup checks. A post-exposure failure enters critical state; database recovery requires separate incident-specific authorization.

The operator authorized proceeding without waiting for branch or PR CI. The established publisher's qualification, embedded binary integrity and manifest checks remain required, followed by production preflight and acceptance. See [release readiness](../M24_RELEASE_READINESS.md) and [updater procedures](../UPDATER.md).

[Published `.14`](https://github.com/firedvl/sub2api-rework/releases/tag/v0.2.3-rework.14) deployed on 2026-10-27 through updater 1.1.6 at unchanged schema 252. [Production acceptance](../M24_ACCEPTANCE.md) records exact artifacts, passed health/preservation/UI checks and one background Gemini Drive-scope 403 log exception.
