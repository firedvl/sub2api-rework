# v0.2.3-rework.25 — Keep stale quota captions readable

The Accounts Capacity view now puts a stale or estimated window warning and its reset countdown on separate lines. The inline separator is removed. Fresh windows retain their single countdown line. This fixes the short-window caption clipping found at 375px during `.24` acceptance. Desktop account rows retain their 52px height.

Only the Accounts fleet component, canonical release version metadata and these notes change. No database migration, provider route, account configuration, billing control or updater change is required.
