# v0.2.3-rework.25 — Keep stale quota captions readable

The Accounts Capacity view now puts a stale or estimated window warning and its reset countdown on separate lines. The inline separator is removed. Fresh windows retain their single countdown line. This fixes the short-window caption clipping found at 375px during `.24` acceptance. Fresh desktop rows remain 52px tall. Production acceptance measured 53px for rows with a two-line stale caption; that one-pixel increase is a remaining limitation.

Only the Accounts fleet component, canonical release version metadata and these notes change. No database migration, provider route, account configuration, billing control or updater change is required. Schema remains 252, supported schemas 239–252, minimum updater 1.1.6, stable channel and manual update policy. The exact `.24` image and the updater's pre-install snapshot provide the rollback target.
