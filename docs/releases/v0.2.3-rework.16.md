# v0.2.3-rework.16 — Fix Claude warm-up model availability

Automatic Claude warm-up and connection tests now default to Sonnet 4.6. The previous dated Sonnet 4.5 model returned upstream `not_found_error` / HTTP 404 for one configured OAuth account. A bounded live request using the replacement model returned HTTP 200, completed its native stream, and supplied a new five-hour reset header. The request was capped at 16 output tokens.

The existing normal `/v1/messages` route already switches from a quota-exhausted Claude OAuth account to another eligible account in the same group. Handler tests verify a 429 handoff with conversation replay, streaming only the successful response, and skipping an account already in quota cooldown. No routing engine or API-key-only policy changes are introduced. The [Claude Code guide](../CLAUDE_CODE_ACCOUNTS.md) now explains the root gateway URL, downstream group key and partial-stream limits.

Schema remains 252, supported schemas 239–252, minimum updater 1.1.6, stable channel and manual update policy. Install through the verified host updater. Existing account opt-ins and credentials are preserved.

[Published `.16`](https://github.com/firedvl/sub2api-rework/releases/tag/v0.2.3-rework.16) deployed through updater 1.1.6 on October 30, 2026 Pacific at schema 252. [Acceptance](../M26_ACCEPTANCE.md) records healthy services, preserved data/backups and both active Claude countdowns.
