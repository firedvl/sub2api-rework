# Operator prototype lab

Question: which page composition, navigation, density, account presentation,
capacity visualization, and visual language should guide the final Sub2API
operator console?

Run `pnpm review:prototypes`, then open `http://127.0.0.1:4174/ui-lab`.
The A-D variants use one synthetic snapshot and make no component-level network
requests. Delete the losing variants and rewrite the selected direction for
production after the visual review.
